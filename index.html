Panduan Cepat & Rumus Dasar Subnetting TKJ
Referensi Praktikum
1. Menghitung Jumlah Host Valid (Usable)
Jumlah Host = 2^h - 2

Di mana h adalah jumlah bit Host (bit berwarna hijau / bernilai 0 pada subnet mask), yaitu 32 - Prefix CIDR. Dikurangi 2 karena alamat pertama dipakai untuk Network ID dan alamat terakhir untuk Broadcast.

2. Menghitung Block Size (Kelipatan Subnet)
Block Size = 256 - Nilai Oktet Mask

Contoh: Pada prefix /26, subnet mask adalah 255.255.255.192. Maka kelipatan blok jaringan pada oktet ke-4 adalah 256 - 192 = 64 (0, 64, 128, 192).

3. Aturan Emas Perancangan VLSM
Urutkan Host Terbesar → Terkecil

Selalu alokasikan subnet untuk ruangan dengan kebutuhan host paling banyak terlebih dahulu agar batas kelipatan blok (boundary) tetap rapi dan tidak tumpang tindih.
